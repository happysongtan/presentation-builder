# Presentation Archive

프로젝트 발표자료를 HTML 형식으로 모아 관리하는 저장소입니다.

각 발표자료는 별도의 HTML 파일로 관리하며, 브라우저에서 바로 열어볼 수 있도록 구성합니다.  
PPT 파일 대신 HTML을 사용하는 이유는 버전 관리가 쉽고, 디자인 수정과 공유가 빠르기 때문입니다.

## 목적

- 프로젝트 발표자료를 한 곳에서 관리
- HTML 기반 발표자료를 Git으로 버전 관리
- 주제별 발표자료를 쉽게 찾고 재사용
- 디자인 템플릿과 폰트 스타일을 일관되게 유지

## 자료 목록

| 제목 | 설명 | 파일 |
| --- | --- | --- |
| 돈독 백엔드 안정화 전략 | 안정화의 의미, 기준, 프로젝트 안정화 프로세스 정리 | `stabilization-deck.html` |
